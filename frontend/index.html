This website however is a part of our latest DevSecOps course. 
        
We used Docker to containerize the application, ensuring it runs consistently across different environments. During the course, we deployed it using Kubernetes within a shared cluster and team namespace, where it was managed with multiple services and resources. As the course environment has since been decommissioned, the application is now deployed using Render.
        
We used Docker to package the app with everything it needs to run, and Kubernetes to manage it inside our team namespace in a shared cluster (although now we use render as the course is coming to an end and our cluster has been decommissioned). 
        
Our CI/CD pipeline automates the process by building the application, creating container images, running security scans, and deploying updates automatically.
        
We also worked with cloud infrastructure to run the application outside of our local machines, making the setup closer to a real-world production environment.
        
Through this project, we’ve gained practical experience in how development, security, and operations come together in a unified DevSecOps workflow.
